# FoodieVerse
A visually stunning landing page for a fictional food discovery platform. FoodieVerse bridges the gap between hungry users and the best local hidden gems.
🎨 UI/UX Highlights

    Responsive Design: Fully optimized for Mobile, Tablet, and Desktop.

    Modern CSS: Utilizes Flexbox and Grid for a clean, masonry-style layout.

    Interactive Menu: Hover effects and smooth scrolling transitions.
